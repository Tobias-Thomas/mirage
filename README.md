# Mirage
For a while now, I wanted to learn more about functional programming and I missed a compiled and typed language, where the compiler saves you from many mistakes.  
Thus, I have started to dig into OCaml and as I also dabble with Probabilistic Programming Languages (PPLs) in my research, I decided to built my own custom one.  
So far, the project is not in any state, that it would be usable but feel free to explore the code, but don't expect anything from my first few lines of OCaml.
